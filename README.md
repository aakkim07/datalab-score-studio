# DataLab

Jednoduchá aplikácia na generovanie a výpočet hodnôt.

- Vygeneruje 50 náhodných čísel od 10 do 100.
- Zobrazí minimum, maximum a priemer poľa.
- Vypočíta vzorec `y = 2x + 10` pre zadané číslo aj všetky hodnoty v poli.
- V grafe porovná pôvodné a vypočítané hodnoty.

## Spustenie v PyCharm

Spusti `main.py` cez **Run**. Projekt používa Tkinter zo štandardnej knižnice Pythonu.

## Testy

```powershell
.venv\Scripts\python.exe -m unittest -v
```

## EXE

Spusti `build_exe.bat`. Nová verzia bude v `dist\DataLab-minimal.exe` a dá sa spustiť bez nainštalovaného Pythonu.
